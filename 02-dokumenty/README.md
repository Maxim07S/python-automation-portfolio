# Договоры и счета в Word из таблицы Excel

**Задача клиента:** менеджер ведёт клиентов в Excel и для каждого вручную копирует данные в договор
и счёт: название, ИНН, адрес, услуги, суммы, сумму прописью. Это долго, и в документы попадают ошибки.

**Решение:** скрипт за секунды делает готовые `.docx` по шаблонам компании для всех клиентов из таблицы.

## Что умеет

- Берёт данные из обычной таблицы Excel: лист «Клиенты» и лист «Позиции» (услуги по каждому договору).
- Заполняет **любые Word-шаблоны клиента**. В его документ вставляются метки вида `{{ company }}`,
  `{{ inn }}`, `{{ total }}`, а оформление остаётся как было.
- **Таблица услуг заполняется автоматически**: сколько позиций, столько строк.
- Считает суммы и пишет **сумму прописью** по правилам русского языка:
  «Двадцать одна тысяча рублей», «Сто один рубль».
- Учитывает разницу между ИП и ООО: «в лице директора…», «именуемый/именуемое».
- **Проверяет данные перед генерацией**: ИНН из 10 или 12 цифр, обязательные поля, наличие позиций.
  Договоры с ошибками не создаются, а попадают в реестр с причиной.
- Создаёт **Реестр.xlsx**: что сформировано, на какую сумму, где лежит, какие ошибки.

## Результат

```
output/
├── 24-101_ООО Ромашка/
│   ├── Договор.docx
│   └── Счёт.docx
├── 24-102_ИП Смирнова Ольга Викторовна/
├── 24-103_ООО Северный ветер/
└── Реестр.xlsx        ← 3 готово, 1 с ошибкой (неверный ИНН, нет позиций)
```

## Запуск

```bash
pip install pandas openpyxl docxtpl
python generate_demo.py        # демо-таблица и шаблоны
python make_documents.py       # сформировать все документы
python make_documents.py --only 24-101   # только один договор
```

## Метки для шаблона

| Метка | Что подставится |
|---|---|
| `{{ number }}`, `{{ date }}` | Номер и дата договора |
| `{{ company }}`, `{{ inn }}`, `{{ address }}`, `{{ email }}` | Данные клиента |
| `{{ signer }}`, `{{ signer_gen }}` | Подписант («Иванов И.П.» и «генерального директора Иванова…») |
| `{{ total }}`, `{{ total_words }}` | Сумма числом и прописью |
| `{{ seller.name }}`, `{{ seller.inn }}`, … | Реквизиты исполнителя |
| `{%tr for it in items %}` … `{%tr endfor %}` | Строки таблицы услуг |

## Под клиента настраивается

- любые типы документов: акты, доверенности, приказы, письма, сертификаты;
- сохранение в PDF (через установленный MS Word или LibreOffice);
- рассылка готовых документов клиентам на почту;
- данные не из Excel, а из Google Таблиц или CRM.

**Стек:** Python, pandas, docxtpl (Jinja2 в Word), python-docx.
