# Парсер каталога с отслеживанием цен

**Задача клиента:** владелец магазина хочет следить за ассортиментом и ценами конкурента:
что подорожало, что подешевело, что появилось или пропало. Сейчас менеджер раз в неделю
листает сайт вручную.

**Решение:** скрипт обходит весь каталог, сохраняет его в Excel и при каждом запуске сам
показывает, что изменилось с прошлого раза.

> Демо работает на [books.toscrape.com](https://books.toscrape.com), сайте, созданном специально для
> практики парсинга. Для реального сайта меняются только CSS-селекторы.

## Что умеет

- Обходит **все категории и все страницы** (постраничная навигация).
- Собирает название, категорию, цену, рейтинг, наличие и ссылку.
- **Работает аккуратно:** пауза между запросами, повтор при сбое сети, таймауты.
  Сайт не перегружается, и случайная ошибка не обрывает сбор.
- Хранит **историю снимков** в `history/` (CSV с датой и временем).
- **Сравнивает с прошлым запуском** по уникальной ссылке товара и подсвечивает цветом:

  | Изменение | Цвет |
  |---|---|
  | Подорожал | красный |
  | Подешевел | зелёный |
  | Новый товар | синий |
  | Пропал из каталога | серый |

## Результат

`output/Каталог_<дата>.xlsx`:

- **Каталог:** все товары, фильтры, кликабельные ссылки.
- **По категориям:** количество, средняя, минимальная и максимальная цена, средний рейтинг.
- **Изменения:** что изменилось с прошлого запуска и на сколько процентов.

Пример: 1 000 товаров из 50 категорий за ~1 минуту (81 запрос). При повторном запуске найдено
8 подорожаний, 7 снижений цены, 3 новых и 2 пропавших товара.

## Запуск

```bash
pip install requests beautifulsoup4 pandas openpyxl
python parse_catalog.py              # полный сбор
python parse_catalog.py --limit 5    # быстрая проверка на 5 категориях
```

Как посмотреть отслеживание изменений на демо-сайте (цены там не меняются):

```bash
python make_demo_changes.py   # создаёт «вчерашний» снимок с другими ценами
python parse_catalog.py       # лист «Изменения» заполнится
```

## Под клиента настраивается

- любой сайт без серьёзной защиты от ботов: селекторы в `parse_product()`;
- сбор с карточек товаров (характеристики, фото, описание);
- запуск по расписанию (Планировщик Windows или cron на сервере);
- уведомление об изменениях цен в Telegram или на почту;
- выгрузка в Google Таблицы вместо Excel.

**Стек:** Python, requests, BeautifulSoup, pandas, openpyxl.
