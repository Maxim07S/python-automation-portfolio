# Сборка Excel-отчётов филиалов в один сводный отчёт

**Задача клиента:** каждый месяц 5 филиалов присылают выгрузки продаж в Excel. Бухгалтер вручную
копирует их в один файл, правит ошибки и строит сводные таблицы. Это занимает полдня.

**Решение:** скрипт на Python делает то же самое за пару секунд одним запуском.

## Что умеет

- Читает все `.xlsx` из папки, **один файл = один филиал**.
- **Сам понимает разные названия колонок**: «Кол-во», «Количество», «кол-во, шт», «Номенклатура», «Наименование» и т.д.
- **Чистит данные:**
  - лишние пробелы, `КОФЕ ЗЕРНОВОЙ` и `кофе зерновой` становятся одним товаром;
  - даты, записанные текстом (`05.07.2026`, `2026-07-05`);
  - дубли строк и пустые строки.
- **Не теряет данные молча.** Строки с ошибками (например, «два» вместо числа) попадают на лист
  «Проблемы» с указанием файла и номера строки, чтобы их можно было исправить.
- Формирует **оформленный отчёт** с итогами, сводными таблицами, графиками, фильтрами и форматом рублей.

## Результат

Файл `output/Сводный_отчёт.xlsx` с листами:

| Лист | Что на нём |
|---|---|
| Итоги | Период, выручка, средний чек, лучший филиал, статистика очистки |
| По филиалам | Выручка, число продаж, средний чек, доля; столбчатая диаграмма |
| По месяцам | Сводная таблица «месяц × филиал»; график динамики |
| Топ товаров | Продано штук и выручка по каждому товару |
| По менеджерам | Рейтинг менеджеров |
| Все продажи | Очищенные данные одной таблицей с фильтрами |
| Проблемы | Строки, которые не удалось обработать, и причина |

Пример на демо-данных: 5 файлов → 736 продаж, удалено 27 дублей, найдено 5 строк с ошибками.

## Запуск

```bash
pip install pandas openpyxl
python generate_demo.py      # создать демо-файлы в input/ (для проверки)
python merge_reports.py      # собрать отчёт в output/
```

Свои папки:

```bash
python merge_reports.py --input "D:/Отчёты/Октябрь" --output "D:/Сводный_октябрь.xlsx"
```

## Под клиента настраивается

- новые варианты названий колонок: словарь `COLUMN_ALIASES` в начале скрипта;
- другие сводные: по категориям, по неделям, план/факт;
- сборка в `.exe`, чтобы запускать двойным щелчком без установки Python;
- автоматическая отправка отчёта на почту или в Telegram.

**Стек:** Python, pandas, openpyxl.
