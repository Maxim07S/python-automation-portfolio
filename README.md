# Автоматизация Excel, документов и сбора данных на Python

Портфолио скриптов, которые снимают с сотрудников рутину: собирают отчёты, заполняют документы
и следят за ценами. Каждый проект работает «из коробки» на демо-данных и проверен запуском.

| # | Проект | Какую рутину убирает | Стек |
|---|---|---|---|
| 1 | [Сборка Excel-отчётов](01-excel-otchety/) | Ручное сведение выгрузок филиалов в один отчёт | pandas, openpyxl |
| 2 | [Договоры и счета из Excel](02-dokumenty/) | Ручное заполнение документов по каждому клиенту | docxtpl, pandas |
| 3 | [Парсер каталога с ценами](03-parser/) | Ручной мониторинг цен и ассортимента конкурентов | requests, BeautifulSoup |

## Принципы работы

- **Данные не теряются молча.** Ошибочные строки попадают в отчёт с причиной и номером строки.
- **Скрипт понимает реальные «грязные» данные:** разные названия колонок, даты текстом, дубли, лишние пробелы.
- **Результат понятен без программиста:** оформленный Excel или Word, а не сырой CSV.
- **Настройки вынесены в начало скрипта,** их легко поменять.
- К каждому проекту есть инструкция по запуску. По запросу скрипт собирается в `.exe`.

## Быстрый старт

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Затем в папке нужного проекта: `python generate_demo.py`, а потом основной скрипт (см. README проекта).
